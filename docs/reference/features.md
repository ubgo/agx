# Feature index

Every feature of agx, from its commands, flags, config keys and environment, with the best guide section for it and a runnable example folder when one exists. Use it to find where a feature is explained. The [command reference](../commands/README.md) lists every flag and the [config reference](../config.md) every key; this page groups them by what you want to do and points at the section that explains each one.

Columns: **Feature** is what it does; **Command/Key** is the command, flag, config key or variable; **Guide** links the section that explains it best; **Example** links a folder under `examples/` that uses it, or shows — when none does yet.

Areas: [Launching](#launching), [Resolution sources](#resolution-sources), [Launch layers](#launch-layers), [Logins](#logins), [Live login, run folders and clean](#live-login-run-folders-and-clean), [Profiles and homes](#profiles-and-homes), [Folder bindings](#folder-bindings), [Conversations and session folders](#conversations-and-session-folders), [Usage](#usage), [Setup and tools](#setup-and-tools), [Shell layer](#shell-layer), [Output](#output), [Exit codes](#exit-codes), [Environment variables](#environment-variables), [Config keys](#config-keys), [Agents](#agents).
